# Summitline Summit Shell (3-layer hardshell)

**SKU:** SUM-SH-01
**Membrane:** Gore-Tex Pro (28k mm hydrostatic head)
**Weight:** 480 g (men's M)
**Sizes:** XS–XXL (men's) and XS–XL (women's)
**Colors:** Slate grey, Alpine green, Sunset orange, Storm black

## Feature summary
- Helmet-compatible hood with wire brim
- Two chest pockets sized for a Summitline topo map, folded quarters
- Full-length pit zips (35 cm)
- YKK AquaGuard main zip

## Not recommended
- Do not layer over a down parka — the shell is sized for a fleece + baselayer, not a heavy insulator
- Do not machine-dry — Gore-Tex Pro delaminates above 60°C. Line-dry only.

## Warranty
5-year seam-tape warranty. If seams peel or bubble, return with proof of purchase.
