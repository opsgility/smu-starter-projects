# az-dev-190-capstone-observability

Anchorline capstone — 4-service system (Web + Orders API + Fulfillment Worker + Notification Function) unified under a single App Insights component with SLO instrumentation, fast + slow burn-rate alerts, a service-catalog workbook, and a Logic App runbook.

This starter contains the Orders API tier with an inducible Cosmos slowdown so you can trigger the incident scenario and drive the on-call runbook end-to-end.

Companion services and the workbook JSON deploy alongside this via the ARM template + the exercise walkthrough.
