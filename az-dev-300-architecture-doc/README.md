# az-dev-300-architecture-doc

TaskForge architecture doc — starter scaffolding.

## Contents
- `docs/ARCHITECTURE.md` — skeleton for the C4 diagrams + service matrix + cost model + risk log
- `docs/PEER-REVIEW-CHECKLIST.md` — printable checklist
- `docs/diagrams/` — put Mermaid + generated PNGs here

## Fill it in
1. Draft the four C4 levels in `ARCHITECTURE.md`
2. Populate the service matrix with why-not columns
3. Add cost model at 10k tenants (per-service breakdown)
4. Write the risk log — at minimum: data leak, region failure, cost overrun, partner-integration break
5. Run the peer-review checklist against your own doc
