# adapter-practice starter

Five functions implemented as imperative `for` loops. Exercises 2-4
refactor each into a one-line iterator chain. Exercise 5 (optional)
adds a sixth function using `.fold()`.

The baseline output you refactor against:

```
sum_evens: 30
double_strings: ["alpha-alpha", "beta-beta", "gamma-gamma"]
zip_names_ages: ["Imani is 42", "Pavel is 37", "Kenji is 29"]
flatten_sublists: [1, 2, 3, 4, 5, 6]
count_matching(> 5): 5
```
