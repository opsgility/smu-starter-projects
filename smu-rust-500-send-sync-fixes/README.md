# smu-rust-500-send-sync-fixes

Starter for Lab 3322 (Course 5, Lesson 6) — Fix the Send/Sync errors.

Six drills in `src/bin/drill01.rs` through `src/bin/drill06.rs`. **Each drill FAILS to compile on purpose.** Each isolates one Send-or-Sync violation. The student fixes each in turn as the exercises walk them through.

The failing build is the lesson, not a bug. Each drill has the expected compiler error documented at the top as a comment.

Course 5 — Concurrent Rust (SMU-RUST-500).
