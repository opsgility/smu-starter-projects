# smu-rust-500-threads-basics

Starter for Lab 3318 (Course 5, Lesson 2) — Spawn, join, and share data by move.

Starts as a serial `sum_slice` baseline over 1 M u64 values. The exercises walk the student through spawning a worker, parallelizing across N workers, and measuring the speedup.
