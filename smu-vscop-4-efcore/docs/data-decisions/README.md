# data-decisions/

ADR-lite folder for data-layer design decisions. One file per decision, Markdown, committed with the PR that lands the implementation.

Template:

```markdown
# Design decision — <name>

**Author:** <who>
**Reviewed:** <who>
**Sprint:** <sprint ID>

## Context

<the one-pager Michael / Christopher / Marcus wrote>

## Decisions

### Decision 1 — <topic>
- <trade-off considered>
- Chosen: <option>, because: <reason>

## Rollback plan

<how the migration + model change comes back out, if it does>

## Future-proofing

<what the next evolution looks like + why this design accommodates it>

## MS Learn references

<links>
```

Lesson 6 Exercise 2 writes `add-customer-tier.md` in this folder as the first ADR for Course 4.
